# ResoIA — resoia.fr

Version claire du site ResoIA (la version sombre est sur resoia.com, dépôt `resoia-site`).

Une page, `index.html`, avec :
- les profils (dirigeant, direction réseau, DAF et juridique) ;
- la méthode Voir, Cadrer, Avancer ;
- un autodiagnostic en dix questions, calculé dans le navigateur ;
- les livrables, les études sourcées, les offres et les prix ;
- un formulaire de contact.

Polices Bricolage Grotesque et Nunito Sans hébergées dans `fonts/` (licence SIL OFL, voir `fonts/LICENCES.txt`). Photos Unsplash retouchées dans `img/`.

Les formulaires envoient vers contact@metivance.com par Web3Forms (clé dans `CLE_WEB3FORMS`, en bas de `index.html`).

Publié par GitHub Pages depuis la branche `main`, domaine `resoia.fr` (fichier `CNAME`, DNS chez OVH).
